Mission control

Observe the work without changing it. See what is running, why, and what the evidence says. 

omnitrix --db .omnitrix/state.db dashboard
# Trusted remote access only:
omnitrix --db /absolute/path/state.db dashboard --host 0.0.0.0 --port 8765

Default: loopback, port 8765. No authentication; use trusted access or an authenticated proxy. Goals, paths, findings and messages may be sensitive. No API key is required. The manager runs separately.

Click a record for details. Status is persisted state, not a process-liveness probe. Recorded knowledge classification does not guarantee freshness; revalidate before reuse. A passing check is not goal completion. Use CLI chat for steering and authorization.

Data boundaries

  • Read-only/query-only SQLite transaction per request; no ownership, schema creation or writes.
  • Five-second visible-page refresh; failures retain the last snapshot and timestamp.
  • Missing DB stays absent. No fake/sample data or model calls.
  • Latest 200 goals and 200 records per category per goal; use CLI export for full history.
  • GET-only routes, allowlisted assets, escaped content and local-only Content Security Policy.

Rebuild HTML docs

pip install -e '.[docs]'
python scripts/build_docs.py
python scripts/build_docs.py --check

HTML ships with the app and needs no external services. Only README remains Markdown. Edit the HTML guides directly; rebuild the bundled site after edits. Machine-consumed role instructions remain Markdown. --check detects generated-page drift.
